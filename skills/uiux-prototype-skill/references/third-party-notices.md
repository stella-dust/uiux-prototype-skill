# Third-party research acknowledgements

`uiux-prototype-skill` is an original, task-focused synthesis of product UI design practices. The projects below were studied for their decision frameworks. This repository does not bundle their skill directories, scripts, component kits, theme catalogs, search databases, photographs or fonts. The integration is written in new words and does not require those skills to be installed.

## Design-reference websites and runtime dependencies

Dribbble, 即时设计社区, Behance and any product screenshots linked from a style study are independent works. A public page or a search result is not permission to republish its images, branding, copy, fonts or product assets. Generated studies should link to and credit sources, distinguish observations from proposals, and only package assets with a suitable license or the user's rights. Original schematic previews can be used when redistribution rights are unknown.

When a later project chooses a third-party component or asset, preserve its required license and notices in that project's deliverable. A recommendation in this skill is not itself a bundled dependency. Review these records if a future release begins incorporating upstream code or substantial verbatim material.
