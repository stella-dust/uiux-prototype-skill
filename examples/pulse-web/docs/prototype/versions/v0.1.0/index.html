Prototype scope

All people, brands, projects and allocations are synthetic. This package changes only browser-local state; there is no account, messaging, scheduling or backend integration. Native application behavior and production performance are outside this Web example.

The style direction was selected under the user's explicit delegation. Browser acceptance evidence and any gaps are recorded in QA.md.
