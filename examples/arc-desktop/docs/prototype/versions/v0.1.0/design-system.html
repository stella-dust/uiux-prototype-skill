间距主步长 4 / 8 / 12 / 16 / 24 / 32px。控件圆角 5–6px；缩略图 5px；弹层 12px。常规表面只用 1px 边框，投影只用于覆盖层。

三栏不是三套系统

标准：204px 导航 + 弹性作品区 + 284px 检查器；≤1020px 检查器折叠为可关闭侧层；≤800px 导航收成图标；≤580px 显示紧凑浏览提示。

网格 4:3 图像，信息放图像下方；列表用缩略图加可比较的元数据。各栏独立滚动，文档不横向溢出。

05 / 动效与无障碍

Hover

180ms / cubic-bezier(.2,.8,.2,1)，仅用于小幅预览与反馈；搜索、切换集合和键盘路径即时响应。减少动态效果时取消位移与骨架动画，保留状态。

键盘操作有明确退路

/ 搜索 · F 收藏 · G 切换视图 · Space 预览 · Esc 关闭。对输入框和系统组合键不拦截；弹层以原生 dialog 管理焦点，所有图标操作有可访问名称。

主流程检查 Tab/Enter、窄窗口、错误恢复和浏览器缩放；原生菜单、Finder、系统权限和真实文件导入均未实现。
