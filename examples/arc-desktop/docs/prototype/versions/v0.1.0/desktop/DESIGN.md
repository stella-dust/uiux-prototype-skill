# Arc Library — Desktop adaptation

继承 [共享规范](../DESIGN.md)，应用入口 [index.html](index.html)。本版只有桌面端，无其他端的缩放副本。

- 桌面重点：三栏上下文、鼠标与键盘并用、稠密可读的元数据、按用户任务提供网格/列表。
- 标准窗口 1440×900；辅助检查 1024×768、800×900、390×844紧凑浏览模式。具体浏览器实测记录在 ../QA.md，计划不作为验收。
- 小于1020检查器变为右侧可关闭层，不占中央宽度；小于800导航以图标呈现并保留可访问名称。
- 不拦截系统Ctrl/Meta/Alt组合键；支持 / F G Space Escape。输入框与原生按钮键盘语义优先。
- 顶部圆点是视觉示意，不代表宿主窗口关闭/最小化。没有本机目录访问、原生拖放、Finder或系统菜单调用。所有图像是 ../assets/art 下12件原创SVG。
- 本地标签、收藏、新集合用localStorage；导出/云协作不在本轮范围。复制详情在浏览器禁止剪贴板时提供手动文本框。
